# raspberry-pi-pwnagotchi
Raspberry Pi Pwnagotchi
A hands-on Raspberry Pi cybersecurity project featuring a Raspberry Pi Zero 2 W and a Waveshare display, built to explore wireless security, Linux-based embedded systems, and hardware integration.

Hardware
Single-board computer: Raspberry Pi Zero 2 W
Display: Waveshare display
Software: Pwnagotchi
Additional components: To be documented as the build is updated

Project Goals
Gain practical experience with Raspberry Pi hardware and Linux.
Explore wireless networking and cybersecurity concepts.
Document the hardware, configuration, and lessons learned.
Develop hands-on technical skills through a practical project.

Skills & Technologies
Raspberry Pi and embedded systems
Linux system administration
Hardware and display integration
Wireless networking fundamentals
Cybersecurity lab tooling
Technical documentation and GitHub version control
